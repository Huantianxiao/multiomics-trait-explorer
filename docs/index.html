Research software demonstration. All included data and biological annotations are simulated. Results illustrate the workflow and do not establish real biological associations or causal effects.

About the project

Trait & Multi-omics is an interactive research prototype built with Python, Streamlit, and LangGraph. Users enter a question, review the proposed analysis plan, and explore results through tables and interactive charts.

The demonstration supports systolic blood pressure (SBP) and HbA1c, combining protein association analysis with simulated RNA expression, microRNA, DNA methylation, Mendelian randomization, regional colocalization, and GO-style enrichment.

How to use it

  1. Click Open app.
  2. Select Guided demo (no API).
  3. Click Explore SBP · all modules, or enter the example question below.
  4. Review the trait, adjustment covariates, analysis modules, and false discovery rate threshold.
  5. Click Run this analysis.
  6. Explore the results and download the results ZIP.

Example question:

Find proteins associated with SBP and integrate all analyses.

Downloads

The app can export result tables, a report, the analysis plan, workflow information, and provenance in a ZIP file.

Optional AI interpretation

Guided demo mode requires no API key. OpenAI API mode requires your own API key and a supported model. Review the app’s displayed transmission scope before enabling it.
